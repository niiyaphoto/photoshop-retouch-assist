# フォトレタッチ補助

Photoshop上で写真のレタッチに使うマスクや調整レイヤーを作成するUXPパネルです。作成したレイヤーはPhotoshopで編集できます。外部通信は行いません。

## できること

- 輝度分布の解析と、明部・暗部・中間調のルミノシティマスク作成
- 中間調コントラスト、色被り補正、彩度マスクの作成
- カーブ、グレーレイヤー、「光と影を描く」方式のドッジ&バーン
- ハイパスによるシャープと、オートン効果・オートンの色味の適用
- ソフトライトのベタ塗りによる色の調整

## インストール

1. このリポジトリの **Releases** を開き、添付された `.ccx` をダウンロードします。
2. `.ccx` をダブルクリックし、Creative Cloud の案内に従ってインストールします。確認画面が出た場合は内容を確認して進めてください。
3. Photoshop の「プラグイン」メニューから「フォトレタッチ補助」を開きます。

開発者向け: UXP Developer Tools で `plugin/manifest.json` を追加して読み込めます。

## 動作環境

- Adobe Photoshop 24.6.0 以降（UXP対応）
- `.ccx` のインストールには Creative Cloud デスクトップアプリ
- ソースからのビルド・テストには Node.js 18 以降

## ビルドとテスト

外部ライブラリなしで実行できます。

```text
node tools/build-ccx.js plugin
npm test
```

生成した `.ccx` は `dist-ccx/` に出力されます。配布用ファイルは Releases に添付します。
